# 验证入口与适用边界

本文件给出可复现入口，不承接重建前的测试通过声明。当前提交的结果应读取实际运行
输出和对应 CI；未运行、未获准执行或缺少平台环境均应明确记录。

- 源码清单：`scripts/Audit-TrackedSource.ps1 -Mode Head`。
- 前端：`npm run check`、`npm test`、`npm run build`。
- Rust 合成测试：`cargo test --locked -p atm-core -p atm-cli -p atm --no-default-features --all-targets`。
- 离线组合入口：`scripts/Verify-Local.sh`；需预先准备依赖。
- macOS 原生隔离入口：`scripts/Verify-MacOS.sh`；内存密钥、临时 HOME 和受控原生二进制，不签名发布或安装。

测试必须使用临时目录、TEST_ONLY 数据、模拟进程或 loopback 服务。不要打开用户现有
vault、Keychain、认证目录、应用配置或真实额度服务。原生 GUI、跨平台存储与持续运行
另需适用平台验收，前端测试与静态检查不能替代这些检查。
